## Shardelix v14.0.0 — Unified classical reconstruction

V14 integrates the irregular and degraded-fragment research into the main
automatic reconstruction workflow. It remains blind by default: no matching
reference, OCR, ML, training data or GPU is required.

### Changes

- Metadata-free irregular matching with compact C++20 canonical chain-code
  indexing, exact contact verification, and spatial component assembly.
- Gap-aware continuous pose recovery with structure-tensor extrapolation,
  line exits, masked FFT proposals and independently verified contextual seams.
- Adaptive native working-set budgets and separate browser resource guards.
- One final component graph with honest unanchored groups and observed pixels.
- Consistent V14 package version, citation, Studio badge, README, and benchmark
  documentation. Existing CLI/API entry points and C ABI remain compatible.

### Evidence and limitations

See [V14 results](https://github.com/Daydreamer2812/Shardelix/blob/v14.0.0/docs/V14_RESULTS.md) for reproducible measurements with raw
data. Historical 100,000-piece exact-lattice native stress is not a
100,000-piece physical-scan or browser claim. Blind DAFNE recovery remains
experimental: the Resurrection development case improves relative join
precision to 6/13 with 3/87 correct primary poses. Reference-assisted DAFNE
measurements are reported separately.
