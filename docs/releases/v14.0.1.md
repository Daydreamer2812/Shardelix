# Shardelix 14.0.1 — architecture maintenance

- Group reconstruction by fragment geometry: tiles, strips, irregular and
  reference-assisted methods.
- Replace version-numbered runtime modules with descriptive names; preserve
  existing matching implementations, diagnostic values and tuning thresholds.
- Separate upload inspection, file-case operations, CLI parsing, pose
  normalization and geometry-specific recovery.
- Keep the public Python API, CLI commands, UI, C++ ABI, and Python/WASM
  fallback unchanged. Independent ground truth remains post-solve only.
- Update web package regression coverage to import every geometry module from
  the packaged engine ZIP.

## Regression evidence

An eight-case paired native run against 14.0.0 (commit `f1f1bbf`) preserved exact pose maps, PNG bytes, deterministic diagnostics and evaluation metrics, including missing pieces and continuous angles. See [paired results](../../reports/v14/refactor_parity.json). Timing columns are illustrative, not a controlled speedup claim.
