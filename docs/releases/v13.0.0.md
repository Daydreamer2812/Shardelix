## Shardelix V13 — C++ / WebAssembly research release

Reconstruct shuffled, rotated, and partially missing digital image fragments with classical computer vision, without neural model training or original-image access during matching.

**[Launch the Web Studio](https://daydreamer2812.github.io/fragmentlab-official/)**

### What's new

- Separate Fragment Generator and Reconstruction tabs, with direct handoff or independent ZIP import.
- Optional ground-truth image or evaluation ZIP, kept out of the solver.
- C++20 kernels for contour extraction, edge descriptors, 2×2 cycle consensus and seam scoring; the same kernels compile to WebAssembly.
- A bounded corrective search for severe Fast-profile irregular under-coverage.
- Benchmark reports and independent reference metrics, responsive layout and reproducible public fragment archives.

### Measured native performance

| Grid fragments (20 px) | Python reference | C++ hybrid | Speedup |
|---:|---:|---:|---:|
| 4,096 | 2.896 s | 1.308 s | 2.21× |
| 16,384 | 11.203 s | 6.540 s | 1.71× |

Both paired cases reached 100% DPA and adjacency F1, without pixel collisions. These are synthetic, native solver-only measurements, not universal accuracy claims or browser speedups. See [benchmark methodology](https://github.com/Daydreamer2812/fragmentlab-official/blob/v13.0.0/docs/V13_RESULTS.md).

### Downloads

- **shardelix-v13.0.0-source.zip** — research code, examples, tests and documentation. Extract, then follow README to install Python dependencies; building native C++ kernels is optional.
- **shardelix-v13.0.0-web.zip** — ready-to-serve HTML, JavaScript, WebAssembly and Python engine bundle. Extract and run `python -m http.server 8767 --bind 127.0.0.1` from the extracted directory. Open http://127.0.0.1:8767/. First use requires internet access for pinned Pyodide dependencies.
- **SHA256SUMS.txt** — SHA-256 checksums for the two ZIP assets.

### Research status

This is an alpha research release. Continuous-angle irregular cases with missing pieces, extremely small low-information fragments, and ambiguous document strips remain open research problems. Global assembly and pose recovery remain Python; this is a hybrid architecture. Public visibility is not a redistribution license; refer to README for usage terms.

Found a difficult case? [Open an issue with the parameters and reproducible evidence](https://github.com/Daydreamer2812/fragmentlab-official/issues/new/choose).
