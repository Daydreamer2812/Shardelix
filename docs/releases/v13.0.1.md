## Shardelix v13.0.1 — Rebrand of FragmentLab

This patch release introduces the Shardelix name across the Studio, Python package, CLI, documentation, build tooling and C++/WebAssembly integration. The V13 reconstruction algorithms and C ABI are unchanged. Existing benchmark measurements refer to V13, not new performance claims.

### Migration

- Install from this source with `python -m pip install -e .`.
- Replace `import fragmentlab` with `import shardelix`.
- Launch the local Studio with `python -m shardelix studio`.
- Use `SHARDELIX_CORE` to choose the engine; the old environment variable is still accepted.

- **shardelix-v13.0.1-source.zip** — code, tests, examples and docs.
