# Security policy

Shardelix is an offline-first research project. It does not require network credentials for
normal operation.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or accidental credential exposure.
Contact the repository owner privately through the GitHub profile associated with this project.
Include affected versions, reproduction steps, impact, and any proposed mitigation.

Only the latest revision on the default branch is currently supported. Never attach private
datasets or secrets to a report unless a secure exchange method has been agreed upon.
